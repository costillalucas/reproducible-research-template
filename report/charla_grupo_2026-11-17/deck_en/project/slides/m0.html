What ptychography is: overlapping windows

FPM Mini-course · images: simulation (256 × 256 object, phase orange +, blue −)

(1.5 min) Three steps, from left to right. 1) The camera measures only intensity, |ψ|²: the amplitude remains, the phase is lost. Any field with the same amplitude and another phase gives the same picture, so a single picture is not enough. 2) Each measurement sees the object through a window: in FPM, the circle of the spectrum that the objective lets through with a given LED. That picture is low resolution. 3) If two windows share part of the spectrum (here ~59 %), that part is measured twice, and the two pictures must be explained by the same field: that constrains the phase. With many overlapping windows only a global phase remains free. Hence the name: classical ptychography (X-rays, electrons) uses windows that are shifted over the sample; FPM uses windows that are shifted in the spectrum. What FPM adds is a synthetic aperture: with a low-NA, large-field objective it builds an image with the resolution of a higher NA, with no moving parts. In our setup: with LEDs up to an illumination NA of ~0.38 the goal is NA ~0.45 in the same ~1.4 mm field.
