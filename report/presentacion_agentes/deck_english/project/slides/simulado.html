We make up a sample, simulate the 169 photos and the program reconstructs from them. Since we know the answer, we can measure how close it gets. This is the foundation: if it did not work here, there would be no point in trying real data. The numbers come from the simulation with the real geometry (matrix at 75 mm, 100 iterations, no noise). With the matrix at 100 mm, which gives more overlap between neighbouring LEDs, the phase rises from 0.87 to 0.97: an argument for changing the geometry in the next captures.
