# Papers Relevantes de 2019 en Fourier Ptychographic Microscopy (FPM)

1. **Illumination Pattern Design with Deep Learning for Single-Shot Fourier Ptychographic Microscopy**
   - *Authors:* Yi Fei Cheng, Megan Strachan, Zachary Weiss, Moniher Deb, Dawn Carone, Vidya Ganapati
   - *Journal:* Optics Express, vol. 27(2), pp. 644-656 (8 ene 2019), open access
   - *Summary:* Usa deep learning para optimizar conjuntamente un único patrón de iluminación LED junto con los parámetros del algoritmo de reconstrucción, usando un dataset de imágenes de alta resolución como entrenamiento. Logra imagen "single-shot" (una sola captura) sin sacrificar el espacio-ancho de banda, reduciendo el tiempo de adquisición hasta 69 veces frente a FPM convencional.
   - *DOI:* [10.1364/OE.27.000644](https://doi.org/10.1364/OE.27.000644)
   - *PDF (descargado):* preprint [arXiv:1810.03481](https://arxiv.org/abs/1810.03481) → `IlluminationPatternDL_Cheng_1810.03481.pdf`

2. **Data-Driven Design for Fourier Ptychographic Microscopy**
   - *Authors:* Michael Kellman, Emrah Bostan, Michael Chen, Laura Waller
   - *Journal:* 2019 IEEE International Conference on Computational Photography (ICCP), mayo 2019
   - *Summary:* Del laboratorio de Laura Waller. Recasta la reconstrucción super-resolutiva de FPM como una red neuronal "physics-based" (basada en el modelo físico de formación de imagen) y aprende el diseño experimental óptimo (patrón de fuente LED) para comprimir el número de mediciones necesarias, logrando un mejor trade-off entre resolución temporal y calidad de reconstrucción, con diseños de iluminación específicos según la aplicación (imagen de amplitud vs. fase cuantitativa).
   - *DOI:* [10.1109/ICCPHOT.2019.8747339](https://doi.org/10.1109/ICCPHOT.2019.8747339)
   - *PDF (descargado):* preprint [arXiv:1904.04175](https://arxiv.org/abs/1904.04175) → `DataDrivenDesign_Kellman_1904.04175.pdf`
